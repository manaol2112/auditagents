## Rules for this register

- A reference is marked **Verified** only where the source text itself was read during preparation of this register.
- **How it was read** is recorded for each source, because the methods differ in reliability:
  - **Text read:** the publisher's document was downloaded, its text extracted, and the cited passage read.
  - **Summary read:** the publisher's page was read through an automated page-summary tool that returned quotations. The page itself was not seen in full.
  - **Not inspected:** nothing from the source was read. Any statement about it comes from memory or a secondary source.
- PCAOB's live website (pcaobus.org) refuses automated access. PCAOB documents were therefore obtained from PCAOB's own document server (assets.pcaobus.org). The live standards pages as they stand today have **not** been inspected.
